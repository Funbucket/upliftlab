upliftlab
비교데이터알고리즘

현재 실행 환경

로컬에서 실행

같은 화면과 엔진을 내 컴퓨터의 Python에서 실행해요. 설치된 패키지와 GPU를 모두 쓸 수 있고, 브라우저보다 큰 데이터를 다룰 수 있어요.

pip install upliftlab
upliftlab                 # 브라우저에 이 화면이 열려요

화면 없이 비교만 돌리고, 결과 JSON을 실행 기록에서 열 수도 있어요.

upliftlab run --data my_experiment.csv --out result.json
