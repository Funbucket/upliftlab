# 오프라인 지표 1위가 운영 루프에서도 1위일까요

오프라인 지표(Qini, AUCC)로 고른 모델과 운영 루프에서 같은 예산으로 증분 성과를 가장 많이 낸 모델이 같은지 확인했어요. 기본 모델 6개를 그대로 쓰고, Random은 비교에서 뺐어요. 오프라인 지표는 사이클마다 배포한 모델을 그 사이클의 Explore 그룹에 적용해 합산한 값이에요(v0.26.2부터).

```bash
python scripts/offline-vs-loop.py result.json   # EconML로 약 2분
```

## 결과

| 데이터 · 선정 방식 | 지표 | 오프라인 1위 = 루프 1위 | 틀렸을 때 루프 손실 | 손실이 유의한 경우 |
| :-- | :-- | --: | --: | --: |
| 합성 쿠폰 시장 · 예산 40% | Qini | 0/10 시드 | 평균 -17% (-12% ~ -26%) | 10/10 |
| 합성 쿠폰 시장 · 예산 40% | AUCC | 10/10 시드 | — | — |
| 합성 쿠폰 시장 · 상위 40% | Qini | 0/10 시드 | 평균 -66% (-49% ~ -87%) | 10/10 |
| 합성 쿠폰 시장 · 상위 40% | AUCC | 10/10 시드 | — | — |
| Criteo · 예산 40% | Qini | 2/6 시드 | 평균 -2.9% | 0/4 |
| Criteo · 예산 40% | AUCC | 2/6 시드 | 평균 -2.9% | 0/4 |

- 손실은 오프라인 1위 모델의 루프 결과가 루프 1위보다 얼마나 낮은지예요. 합성 데이터는 참값(예산 방식이면 증분 성과, 상위 q%면 효율 개선), Criteo는 관측값이에요.
- 유의는 1위와의 차이의 95% CI가 0을 포함하지 않는다는 뜻이에요. 합성 데이터의 참값 차이는 표본 오차가 없어서, 차이가 있으면 모두 유의로 셌어요.

## 읽는 법

**비용이 사용자마다 다르면 Qini로 고르면 틀려요.** 합성 쿠폰 시장에서 쿠폰 비용은 평균 결제액에 비례해요(0.8 + 3.6c). 결제액이 큰 사용자는 효과도 있지만 비용이 더 커요. Qini는 비용을 보지 않아서, 증분 성과만으로 순위를 매기는 X-Learner, T-Learner, DML, R-Learner 중 하나를 매번 1위로 골랐고, 같은 예산에서 Duality R-Learner보다 증분 성과가 평균 17% 적었어요. 비용을 함께 보는 AUCC는 10번 모두 루프 1위와 같은 모델을 골랐어요(순위 상관 +0.88, 상위 40%는 +0.93).

**비용이 같고 모델끼리 차이가 작으면 1위를 고를 근거가 없어요.** Criteo는 처치 비용이 모두 1이라 Qini와 AUCC가 거의 같은 순위를 내요. 시드 6개에서 루프 1위가 X-Learner 3번, DML, R-Learner, Duality R-Learner 각 1번으로 바뀌었고, 오프라인 1위가 틀린 4번 모두 손실이 95% CI 안이었어요. 이 데이터에서 확실한 차이는 학습한 모델과 Random 사이에만 있어요(예시 결과 +71%).

## 한계

- 합성 쿠폰 시장은 이 프로젝트가 만든 시장이에요. 비용이 사용자 특성에 따라 크게 달라지도록 설계했으므로, 실제 데이터에서 손실 크기는 비용의 이질성에 따라 달라요.
- 기본 모델 6개만 비교했어요. 비용을 함께 보는 모델은 Duality R-Learner 하나예요.
- 실험 데이터는 Criteo 하나예요. 비용 열이 있는 실제 실험 로그로 같은 비교를 해 보는 것이 다음 단계예요.
